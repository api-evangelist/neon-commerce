## API Reference
- [Merge player accounts](https://docs.neonpay.com/reference/mergeaccounts.md): API to initiate the merging of player accounts. At the moment, this is only supported for managing accounts at the global level across environments.
- [Unmerge player accounts](https://docs.neonpay.com/reference/unmergeaccounts.md): API to initiate the unmerging of player accounts. At the moment, this is only supported for managing accounts at the global level across environments.
- [Returns the list of brand images associated with the environment](https://docs.neonpay.com/reference/getbrandimages.md): Brand images can be used for customizing the storefront or checkout experience
- [Upload a brand image](https://docs.neonpay.com/reference/createbrandimage.md): Brand images can be used for customizing the storefront or checkout experience
- [Mark a brand image as deleted.](https://docs.neonpay.com/reference/deletebrandimage.md): The deleted image's url will continue to work but the image won't be assignable.
- [Returns the list of inventory images associated with the environment](https://docs.neonpay.com/reference/getinventoryimages.md): Inventory images can be associated with offers and/or items within the same environment.
- [Upload an inventory image.](https://docs.neonpay.com/reference/createinventoryimage.md): Inventory images can be associated with offers and/or items within the same environment.
- [Mark an inventory image as deleted.](https://docs.neonpay.com/reference/deleteinventoryimage.md): The deleted image's url will continue to work but the image won't be assignable.
- [Retrieve a client token](https://docs.neonpay.com/reference/createclienttoken.md): This endpoint issues a client token that can be used with client-side requests to the Neon APIs. Expires in 24 hours.
- [Retrieve a token](https://docs.neonpay.com/reference/createtoken.md): In order to authenticate a shop user with your game, you need to link the player "code" with your internal player account ID. This endpoint does that linking and returns a unique token that can be used to redirect the player back to the shop with an authenticated session.
- [Create a checkout](https://docs.neonpay.com/reference/createcheckout.md): Create a checkout. Once the checkout is created, redirect the user to the `redirectUrl`. On success, we'll send a `purchase.completed` event to your webhook listener. On payment failure, we'll send a `payment.failed` event to your webhook listener. Don't use this API if you have a Neon storefront set up. Neon storefronts handle creating checkouts on your behalf.
- [Returns a checkout's details.](https://docs.neonpay.com/reference/getcheckout.md): Can be used to get the status of a particular checkout.
- [Expire a checkout](https://docs.neonpay.com/reference/expirecheckout.md): Expire a checkout. This will expire the checkout corresponding to the provided checkoutId regardless of the current status.
- [Get localized pricing by country or IP address.](https://docs.neonpay.com/reference/getlocalizedpricingbyipaddressorcountry.md)
- [Get your active pricing sheet. If you don't have a custom pricing sheet, the default Neon pricing sheet is returned.](https://docs.neonpay.com/reference/getactivepricingsheet.md)
- [Create a checkout using a client token](https://docs.neonpay.com/reference/createcheckoutclient.md): Create a checkout. Once the checkout is created, redirect the user to the `redirectUrl`. See [Create a checkout using a client token](https://docs.neonpay.com/reference/createcheckoutclient) for more information. Don't use this API if you have a Neon storefront set up. Neon storefronts handle creating checkouts on your behalf.
- [List all of your Payouts](https://docs.neonpay.com/reference/getpayouts.md)
- [Get all available purchases for a specific environment](https://docs.neonpay.com/reference/getpurchases.md)
- [Get a purchase](https://docs.neonpay.com/reference/getpurchase.md): Get a purchase by its ID
- [Refunds a purchase.
](https://docs.neonpay.com/reference/refundpurchase.md): Refunds are typically handled by Neon. Please reach out to Neon to determine if you qualify for access to this API.
- [Search for a purchase by checkout ID or order number](https://docs.neonpay.com/reference/findpurchase.md)
- [Subscribe to purchase lifecycle events](https://docs.neonpay.com/reference/subscribetowebhooks.md): Learn more about webhooks [here](https://neonpay.readme.io/docs/webhooks-and-callbacks).
- [Mark an unclaimed purchase as claimed](https://docs.neonpay.com/reference/clientclaimpurchase.md): Mark a purchase as claimed. This is required if you are using a serverless flow. The response is signed with `X-Neon-Signature-` headers for verification. To verify the signature, construct the payload as `{timestamp}.{responseBody}` and verify using the public key from the dashboard.
- [Get all unclaimed purchases for a particular user](https://docs.neonpay.com/reference/clientgetpurchasesunclaimed.md): Returns a data object containing the list of unclaimed purchases for the user. The response is signed with `X-Neon-Signature-` headers for verification. To verify the signature, construct the payload as `{timestamp}.{responseBody}` and verify using the public key from the dashboard.
- [Get all available refunds for a specific environment](https://docs.neonpay.com/reference/getpurchaserefunds.md)
- [Retrieve Report details](https://docs.neonpay.com/reference/getreport.md)
- [Get the current status of the Neon API](https://docs.neonpay.com/reference/getstatus.md)
- [Register a URL to handle events throughout the storefront and checkout flow.](https://docs.neonpay.com/reference/subscribetocallbacks.md): Learn more about callbacks [here](https://neonpay.readme.io/docs/webhooks-and-callbacks).
- [Get an item by code](https://docs.neonpay.com/reference/getstorefrontitem.md): Get an item by its code.
- [Update an item by code](https://docs.neonpay.com/reference/updatestorefrontitem.md): Update an item. This replaces the existing item with the input data.
- [Delete an item](https://docs.neonpay.com/reference/deletestorefrontitem.md): Delete an item by its code.
- [Create items](https://docs.neonpay.com/reference/createstorefrontitems.md): Create items. Read more about inventory setup [here](https://neonpay.readme.io/docs/offers). If any operation fails, the error is returned and all changes are reverted.
- [Get an offer group by code](https://docs.neonpay.com/reference/getstorefrontoffergroup.md): Get an offer group by its code.
- [Update an offer group by code](https://docs.neonpay.com/reference/updatestorefrontoffergroup.md): Update an offer group. This replaces the existing offer group with the input data.
- [Delete an offer group](https://docs.neonpay.com/reference/deletestorefrontoffergroup.md): Delete an offer by its code.
- [Create an offer group](https://docs.neonpay.com/reference/createstorefrontoffergroups.md): Offer groups are used to group offers in the storefront. Read more about inventory setup [here](https://neonpay.readme.io/docs/offers). This operation takes a list of offer groups and adds them to your existing offer groups. If any operation fails, all changes are reverted and the error is returned.
- [Create offers](https://docs.neonpay.com/reference/createstorefrontoffers.md): An offer is the resource that players purchase on the storefront. Read more about inventory setup [here](https://neonpay.readme.io/docs/offers). This operation takes a list of offer objects and adds them to your existing offers. If any operation fails, all changes are reverted and the error is returned.
- [Get offers](https://docs.neonpay.com/reference/getstorefrontoffers.md): Get a paginated list of offers.
- [Get an offer by SKU](https://docs.neonpay.com/reference/getstorefrontoffer.md): Get an offer by its SKU.
- [Update an offer by SKU](https://docs.neonpay.com/reference/updatestorefrontoffer.md): Update an offer. This replaces the existing offer with the input data.
- [Delete an offer](https://docs.neonpay.com/reference/deletestorefrontoffer.md): Delete an offer by its SKU.
- [Get localized pricing by IP address.](https://docs.neonpay.com/reference/getregionalpricingbyipaddress.md)
- [Get a storefront theme](https://docs.neonpay.com/reference/gettheme.md): Get a storefront theme
- [Update the theme for a storefront](https://docs.neonpay.com/reference/updatetheme.md): Programatically update the configuration for a theme
- [Create a subscription](https://docs.neonpay.com/reference/postsubscription.md): Create a subscription. Once the subscription is created, redirect the user to the `returnUrl`.
- [Returns a subscription's details.](https://docs.neonpay.com/reference/getsubscription.md): Can be used to get the status of a particular subscription.
- [Cancel a subscription](https://docs.neonpay.com/reference/cancelsubscription.md): Cancel a subscription.
- [Generate a payment method update link](https://docs.neonpay.com/reference/generateupdatepaymentmethodurl.md): Returns a redirect URL where the user can update their subscription's payment method. The URL expires after 1 hour.
