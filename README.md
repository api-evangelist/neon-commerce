Neon Commerce (Neon) is the direct-to-consumer commerce and payments platform for mobile and PC game developers, backed by a16z Games, Thrive Capital, Griffin Gaming Partners and Ribbit Capital. Neon lets studios launch a branded web storefront (Neon Shop), embed or host checkout (Neon Checkout), and accept global payments across 50+ markets and 30+ payment methods as merchant of record — shifting revenue away from app-store fees to owned direct-to-consumer channels. The Neon API (base https://api.neonpay.com) exposes storefront/offer/item management, checkout and subscription creation, purchase and refund lookups, payouts, reports, player authentication, brand/inventory image assets, and a full webhook/callback event surface, with sandbox and production environments scoped by API key.

**Areas:** Commerce · Payments · Gaming · Checkout · Storefront · Direct to Consumer · Subscription · Merchant of Record · Game Monetization · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).
